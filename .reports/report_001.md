# report_001: 3目並べ強化学習教材(ex001〜ex006)の実装・実験報告

対応する指示: `.orders/order_001.md`

## 1. 実施内容の概要

`.orders/order_001.md`の指示に基づき，3目並べを題材とした強化学習の段階的学習教材リポジトリを
新規に構築した．環境をNumPyのみでフルスクラッチ実装し，ランダムプレイ(ex001)，
方策反復法(ex002)，価値反復法(ex003)，モンテカルロ制御(ex004)，Q学習(ex005)を実装した上で，
5手法の総合比較と対人対戦機能(ex006)を実装した．全ての実験ノートブックは
`jupyter nbconvert --to notebook --execute --inplace`により実行し，エラーなく完了することを
確認した．あわせて，`outputs/`配下の結果を横断的に可視化する`visualize_result.ipynb`，
リポジトリ全体の説明を行う`README.md`と`document.md`を作成した．

作成した主なファイルは以下の通りである．

- `README.md`, `document.md`
- `requirements_numpy.txt`, `.venv_numpy/`(Python 3.11, uv管理), `.vscode/settings.json`
- `ex001_random_baseline.ipynb`, `ex002_policy_iteration.ipynb`, `ex003_value_iteration.ipynb`,
  `ex004_monte_carlo.ipynb`, `ex005_q_learning.ipynb`, `ex006_comparison_and_play.ipynb`
  (各ノートブック内に理論解説・実験条件・実験前後の問い・考察・発展課題を含む)
- `ex001_random_baseline.md`〜`ex006_comparison_and_play.md`
  (各ノートブックのMarkdownセルの内容をまとめた解説ファイル)
- `visualize_result.ipynb`
- `figures/ex001/`〜`figures/ex006/`(各実験のグラフ画像)
- `outputs/`(各実験の学習結果，`.gitignore`によりGit管理対象外)

## 2. 実験条件

全実験に共通する設定は`README.md`4節の通りである．

| パラメータ | 値 |
| :--- | :--- |
| 割引率 $ \gamma $ | 0.95 |
| DP収束判定閾値 $ \theta $ | 1e-4 |
| 探索率 $ \epsilon $(MC・Q学習) | 0.1 |
| 学習率 $ \alpha $(Q学習) | 0.1 |
| 学習エピソード数(MC・Q学習) | 50,000 |
| 評価エピソード数 | 1,000 |
| シード | 0, 1, 2 |

環境は，学習エージェントを常に先手(X)とし，後手(O)は合法手から一様ランダムに行動する
固定方策に従うという設定で統一した(詳細は`README.md`1節および各`exNNN_*.ipynb`の
「2.1 環境・エージェント定義」を参照)．

## 3. 実験結果

### 3.1 ex001: ランダムプレイのベースライン

到達可能な状態数は，全終端状態を含めて5,478，Xの手番かつ非終端の状態は2,423であることを
`TicTacToeEnv.enumerate_states`により確認した．ランダム方策同士の対戦(3シード平均，
評価1,000エピソード)の成績は次の通りである．

- 勝率: $ 0.583 \pm 0.020 $
- 引き分け率: $ 0.121 \pm 0.011 $
- 敗率: $ 0.296 \pm 0.018 $

評価エピソード数を50〜10,000まで変化させた際の勝率推定値の収束は
`figures/ex001/win_rate_convergence.png`の通りであり，評価エピソード数が小さいほど
シード間のばらつきが大きいことを確認した．

### 3.2 ex002・ex003: 動的計画法(方策反復法・価値反復法)

方策反復法・価値反復法とも，3シードいずれも同一の最適価値関数へ収束し
(Q値の最大差 $ 0.000000 $，`ex003`内で確認)，対ランダム方策の成績(3シード平均)は
いずれも次の通りであった．

- 勝率: $ 0.996 \pm 0.002 $，引き分け率: $ 0.004 \pm 0.002 $，敗率: $ 0.000 $

収束に要したスイープ数は，方策反復法が14〜15スイープ(外側の方策改善4回)，
価値反復法が5スイープであり，価値反復法の方が少ないスイープ数で収束した．
両手法の収束曲線の比較は`figures/ex002/policy_iteration_convergence.png`および
`figures/ex003/vi_vs_pi_convergence.png`の通りである．学習時間はいずれも1秒未満
(方策反復法 約0.32秒，価値反復法 約0.26秒，1シードあたり)であった．

### 3.3 ex004・ex005: モンテカルロ制御・Q学習

50,000エピソードの学習後(3シード平均，学習時間はモンテカルロ制御が約5.2秒，
Q学習が約5.8秒)，対ランダム方策の成績は次の通りであった．

- モンテカルロ制御: 勝率 $ 0.988 \pm 0.007 $，引き分け率 $ 0.011 \pm 0.005 $，敗率 $ 0.002 \pm 0.002 $
- Q学習: 勝率 $ 0.981 \pm 0.004 $，引き分け率 $ 0.019 \pm 0.004 $，敗率 $ 0.000 $

両手法とも動的計画法に近い勝率へ到達した．学習曲線は`figures/ex004/mc_learning_curve.png`
(モンテカルロ制御単体)，`figures/ex005/ql_vs_mc_learning_curve.png`
(Q学習とモンテカルロ制御seed=0の比較)の通りである．

### 3.4 ex006: 総合比較

対ランダム方策の勝率比較(`figures/ex006/win_rate_vs_random.png`)に加え，
「先手が一様ランダムに打つ場合に最適に打つ後手」を価値反復法により新たに構築し，
これに対する各手法の先手エージェントの成績を測定した
(`figures/ex006/vs_optimal_opponent.png`)．結果は次の通りである(評価1,000エピソード)．

| 手法 | 勝率 | 引き分け率 | 敗率 |
| :--- | ---: | ---: | ---: |
| RandomAgent | 0.003 | 0.069 | 0.928 |
| PolicyIteration | 0.000 | 1.000 | 0.000 |
| ValueIteration | 0.000 | 1.000 | 0.000 |
| MonteCarloControl | 0.000 | 1.000 | 0.000 |
| QLearning | 0.000 | 1.000 | 0.000 |

対ランダム方策では動的計画法よりわずかに劣る成績であったモンテカルロ制御・Q学習も，
最も付け入る隙のない相手(最適な後手)に対しては敗率0・引き分け率100%を達成し，
50,000エピソードという学習量が3目並べ(2,423状態)の状態空間に対して十分であったことを
実証的に確認した．一方，ランダム方策は最適な後手に対して敗率92.8%であり，
対ランダム方策評価だけでは見えにくかった手法間の実力差が，強い評価基準を用いることで
明確になることを確認した．

## 4. 考察

方策反復法と価値反復法は，異なる初期方策(シード)から出発しても同一の最適解に収束し，
既知の環境モデルを用いる動的計画法の理論的性質(有限MDPにおける最適解への収束保証)を
実証した．価値反復法は方策評価を収束まで待たない分，方策反復法よりも少ないスイープ数
(5 vs 14〜15)で収束したが，計算量のオーダー自体は同程度であり，いずれも状態数(2,423)に
比例した計算コストを要する．この計算コストは，動的計画法が既知の環境モデルと
全状態の反復を前提とすることに起因し，状態数が本実験よりはるかに大きい問題への
適用を困難にする．

モンテカルロ制御・Q学習は，環境モデルを一切用いずサンプルエピソードのみから学習したにも
かかわらず，本実験の設定(学習エピソード数50,000)では最終的に動的計画法と同一の
最適方策(最適な後手に対して敗率0)に到達した．これは，3目並べという状態空間の小さい
問題では，モデルフリー手法もモデルベース手法と同等の精度に到達し得ることを示す一方，
対ランダム方策での成績には(統計的に有意ではない範囲ながら)動的計画法よりわずかな
劣位が観測されており，モデルフリー手法が有限サンプルに由来する推定誤差を内在的に
持つことも確認された．
